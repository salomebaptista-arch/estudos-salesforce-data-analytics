🚀 Aprendizado: Estruturação de Dados no Salesforce
Nesta etapa do projeto, foquei na criação da arquitetura de objetos para o sistema de gestão imobiliária. O maior aprendizado foi compreender que a existência de um dado no "back-end" não garante sua visibilidade no "front-end".

🔑 Conceitos Chave Implementados:
Custom Objects (Objetos Personalizados): Criação das tabelas Property (Propriedade) e Offer (Oferta) para estruturar o banco de dados.

Custom Fields (Campos Personalizados): Implementação de tipos específicos de dados como Currency (Moeda), Date (Data) e Auto Number para garantir a integridade da informação.

Custom Tabs (Guias): Entendimento da camada de interface. Aprendi que, para um objeto ser acessível ao usuário final, é necessário configurar manualmente sua Guia de Navegação.

💡 Insight de Ciência de Dados:
A dificuldade em localizar objetos recém-criados reforçou a importância da Governança de Dados. Para um Analista, entender o fluxo desde a criação do objeto até o registro do dado é essencial para garantir que a coleta de informações seja eficiente e livre de erros de interface.
